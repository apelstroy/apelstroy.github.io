## Как добавить или обновить тур без Claude
1. Войти на github.com, открыть этот репозиторий.
2. Новый дом: **Add file → Create new file**, в имени набрать `название-дома/README.md` (с косой чертой — так создаётся папка), написать пару слов, **Commit changes**.
3. Открыть папку дома → **Add file → Upload files** → перетащить файл тура, **переименованный в `index.html`** → **Commit changes**.
4. Через 1–2 минуты тур открывается по адресу `https://<имя>.github.io/название-дома/`.
5. Добавить строку в таблицу выше и кнопку в `index.html` (или попросить Claude).

Названия папок — латиницей, без пробелов: `dom-120`, `dom-banya`.
